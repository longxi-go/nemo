# nemo v0.2.0

Add nested placeholder keys and protect resolution diagnostics from values used
to construct dynamic property names. Requires Go 1.27.0 or later.

- Resolve expressions such as `${${stage}.url:localhost}` before property lookup.
  Nested keys share cycle detection, depth, output-size and cancellation limits
  with values and defaults; escaped placeholders remain literal.
- Omit dynamically expanded keys from printable error metadata while preserving
  error classification and causes. Static property references retain their
  diagnostic keys and paths.
- Preserve the previous environment snapshot when dynamic-key resolution fails
  during refresh, with regression coverage through the public Environment API.
- Separate environment candidate preparation from publication and clarify
  compiler, binding and source-admission responsibilities.
- Use gosr v0.1.2 and gosr/tools v0.1.1. Verify standalone module resolution
  independently of the optional local ecosystem workspace.
- Make tagged publication repeatable by reusing matching Releases and waiting
  for GitHub Latest visibility before deploying documentation.

The release retains generated typed binding and immutable snapshots. It does not
add configuration-center SDK adapters, automatic rebinding or Web integration.
