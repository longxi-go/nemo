# nemo v0.1.0

Add configuration environments and annotation-based typed binding implementing
the gosr environment contracts. Requires Go 1.27.0 or later.

- Compose explicit property sources with first-source precedence and origin metadata.
- Decode JSON, YAML/YML, TOML, INI and Java properties; support application-owned
  decoder registries, file/OS/map sources and profile-based file discovery.
- Resolve placeholders into immutable snapshots, validate complete candidates
  before atomic publication and preserve the prior snapshot on preparation failure.
- Generate `BindProperties` and `PropertyPrefix` from `+nemo:config:prefix` comments
  and field tags. Support multi-level prefixes, scalar and object collections,
  anonymous nested objects and bounded recursion without runtime reflection or unsafe
  in the binding path.
- Serialize refresh preparation with cancellation-aware admission. Coalesce watcher
  invalidations through one refresh worker and deliver change notifications after commit.
- Enforce document, source, value-tree and aggregate byte limits before publication.
- Format and type-check generated output before writing; provide read-only inspection
  and freshness checks with output ownership validation.
- Document annotations, configuration semantics, binding, generation and extension
  contracts in English and Simplified Chinese.

Configuration-center SDK adapters and framework lifecycle integrations are not included.
