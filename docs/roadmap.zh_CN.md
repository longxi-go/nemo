# Nemo 路线图

[English](roadmap.md) | [简体中文](roadmap.zh_CN.md)

| 阶段 | 能力 | 可用行为 | 状态 |
| --- | --- | --- | --- |
| 配置源 | 不可变值，文件、OS、Map 配置源，JSON/YAML/TOML/INI/properties 解码器，基于 Profile 的文件发现及应用级解码器注册表 | 显式组合配置源，分离传输与解码 | 已实现 |
| 环境 | 配置源优先级、占位符解析、Profile、不可变快照、验证与刷新 | 完整准备候选快照后原子发布；失败时保留原快照 | 已实现 |
| 类型化绑定 | 标量/对象集合、命名/匿名嵌套、有界递归、注解编译器和 CLI | 生成类型化 `BindProperties` 方法，写入前验证生成结果 | 已实现 |
| 更新集成 | Provider 订阅和变更通知接口 | 将应用管理的更新传输接入刷新与取消流程 | 已实现 |
| 资源与并发限制 | 候选预算、有界文件输入、可取消的刷新准入和失效通知合并 | 超限候选不进入发布；刷新期间到达的更新保留到后继一轮处理 | 已实现 |
| 远程适配器 | Nacos 及其他配置中心传输 | 为每个适配器定义 SDK 所有权、版本新鲜度、重连与取消行为 | 计划中 |
| 框架集成 | 应用启动与关闭集成 | 在使用方框架中明确首次加载失败处理和生命周期所有权 | 计划中 |

已实现阶段包含受支持行为及失败路径的测试，这些测试不代表与具体远程服务兼容。
远程适配器和框架集成仍需各自的设计与集成测试；当前模块不包含远程 SDK 适配器。
